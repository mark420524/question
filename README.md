# 早晚答题小程序

**master是目前已上线的小程序主分支**

**miniprogram目录是小程序开发的内容，src是准备用uni-app重写的页面，写完后小程序目录会移除**

*develop 是开发分支，代码迁移到uni-app 并且全部用ai重写*
